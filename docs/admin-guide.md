# Инструкция администратора

## Пользователи
**Админ → Пользователи → «+ Добавить»**: ФИО, email, роль, подразделение. Система создаёт ссылку-приглашение (действует 72 ч) и отправляет её на почту; ссылку можно скопировать и передать лично. По ней человек задаёт пароль.
- **Заблокировать** — вход закрывается, действующие сессии прекращаются при следующем запросе. Себя заблокировать нельзя.
- **Сбросить пароль** — старый пароль перестаёт работать, выдаётся новая ссылка.
- Роль и подразделение меняются в таблице. Саморегистрация работает только если задан `ALLOWED_EMAIL_DOMAIN`.

## Справочники
**Админ → Справочники**: добавить, переименовать, «В архив». Архивные элементы скрыты из выбора, но остаются в старых заявках.

## Ответственный
Снабженец нажимает «Взять в работу» (или первым переводит заявку в «На согласовании»). Админ может назначить любого сотрудника снабжения. Статус меняет ответственный или админ.

## Развёртывание
1. `cp .env.prod.example .env`, заполнить `DOMAIN`, `POSTGRES_PASSWORD`, `JWT_SECRET`, SMTP.
2. DNS-запись домена → IP сервера, открыть порты 80 и 443 (5432 наружу не публикуется).
3. `docker compose -f docker-compose.prod.yml up -d --build` — Caddy сам получит HTTPS-сертификат.
4. Первого администратора создать: `docker compose -f docker-compose.prod.yml exec app node --env-file=/dev/null scripts/seed.js` с переменными `ADMIN_EMAIL` (и при желании `ADMIN_PASSWORD`); пароль, если не задан, будет напечатан один раз.
   Пример: `docker compose -f docker-compose.prod.yml exec -e ADMIN_EMAIL=admin@company.kz app node scripts/seed.js`

## Резервные копии
Контейнер `backup` ежедневно делает `pg_dump` и архив вложений в `./backups`, хранит 14 дней. Восстановление — `deploy/restore.md`.

## Логи
`docker compose -f docker-compose.prod.yml logs -f app` — JSON (pino): id запроса и id пользователя; пароли и токены не логируются (в путях ссылок-приглашений токен заменяется на `***`; без SMTP в production текст писем в лог не выводится — ссылку берите из интерфейса администратора). Если логи до обновления могли попасть к посторонним, выдайте новые ссылки тем, чьи приглашения ещё действуют.
